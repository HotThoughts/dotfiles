# Global agent instructions

- Inspect the repository's local instructions before changing files.
- Keep changes scoped to the request and preserve unrelated work.
- Ask before destructive, irreversible, or externally visible actions.
- Do not edit generated files when a source template or generator exists.
- Reproduce bugs before fixing them and verify behavior after changes.
- Prefer maintainable, well-tested changes over broad rewrites.
- Never add agent attribution or co-author trailers to commits.
